# EES1118 / EESD28 Ecological Modelling: course model code

Model code used in EES1118H (Fundamentals of Ecological Modelling, graduate) and EESD28H3 (undergraduate), Department of Physical and Environmental Sciences, University of Toronto Scarborough. Instructor: Alex Neumann.

## Contents

* `Eutro_model_O_v2.R` — eutrophication model for the Lake Washington project (Lectures 7, 8 and 10). A nutrient, phytoplankton, zooplankton, detritus (NPZD-type) system of four ordinary differential equations with seasonal forcing, solved with deSolve. State variables: PO4, PHYT, ZOOP, DET.
* `Lotka_Voltera_model_2025.R` — Lotka-Volterra population model used in the population dynamics lectures (Lecture 2), the aggregate model against which the course's agent-based population project is compared.

## Course assessment context

Students build models in stages across the term: a modelling project proposal (20 percent), a mid-term project (20 percent), a final project (30 percent) and a final oral presentation of the project (20 percent), with participation at 10 percent. The final examination is the oral presentation. There is no written exam.
